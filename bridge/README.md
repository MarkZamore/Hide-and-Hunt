# Адаптер сети Hide and Hunt

Для Minecraft 26.3 с Fabric Loader 0.20.1. Сборка адаптера проверяет SHA256
архива FaWrAGlY и его компонента для 26.3, затем компилирует отдельный Fabric
JAR. Сам игровой JAR готовит [`tools/prepare_26_3.py`](../tools/prepare_26_3.py).

Адаптер убирает переключатель из формы создания мира и отключает авторские
ветки реле и UPnP после публикации. Ранее сохранённое значение флажка больше
не влияет на публикацию. `Hosting.joined` вызывает штатный Minecraft API,
через который e4steam получает событие об открытии мира.
При открытии из меню Hide and Hunt мост передаёт сохранённое разрешение
команд мира в штатный параметр доступа гостя. Публикация больше не выдаёт
хосту постоянный OP. Существующие записи операторов и настройки мира
сохраняются.

В меню Hide and Hunt остаются локальные миры и вручную сохранённые адреса.
Автоматические Steam-миры видны в основном экране Minecraft «Сетевая игра».
Пакет отключает авторский запуск LAN-сканера. В списке авторских миров
используется подпись Steam.

Адаптер проверяет SHA256 четырёх авторских классов и сигнатуры затронутых
методов. При обновлении авторской версии эти привязки проверяются заново.

```powershell
$env:JAVA_HOME = 'C:\Tools\jdk-25.0.2'
python -B bridge/build.py --client-jar <26.3.jar> --upstream <авторский.jar> --out <стенд>/lanminecraft-hide-and-hunt-bridge-1.1.1.jar
```

Параметр `--libraries-root` позволяет переиспользовать уже проверенный кеш
библиотек. По умолчанию кеш создаётся рядом с выходным JAR. Библиотеки
компиляции берутся из официального Maven Fabric по SHA256 из `inputs.json`.
Сборка проверяет байткод фактических авторских классов. В проверку входят
штатный вызов публикации, удаление флажка и UPnP, ручной список и отсутствие
запуска авторского LAN-сканера. Проверка запуска Minecraft выполняется отдельно.
