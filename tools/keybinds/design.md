# Пресет управления Hide and Hunt

**H** перебирает размеры HUD Hide and Hunt. Пресет повторяет все 63 назначения
из `options.txt` установленной сборки по состоянию на 16 ноября 2026 года.
Клавиша H также используется в отладочном сочетании F3+H. Все 62 назначения Minecraft сохранены,
в том числе привычные WASD, Shift, Ctrl, управление мышью, чат и панель 1–9.
Два штатно неназначенных действия оставлены такими же.

Проверка допускает 16 групп стандартных пересечений и пару H / F3+H. СКМ используется
в разных режимах игры для выбора блока и панели наблюдателя. F3 открывает
отладку и служит её модификатором. Остальные группы используют F3 как
модификатор. F3+C различает короткое нажатие и удержание. Встроенные формы
Hide and Hunt принимают ввод через собственный экран. Пересечения с буквами
в мини-играх, например P для паузы, ограничены этими экранами. HUD использует
обычный `KeyMapping` Fabric. Пресет задаёт только строки `key_` файла
`options.txt`.

Fabric Loader 0.20.1 и Java 25.0.2. Все 63 записи совпали со строками, которые
клиент записал в тестовый `options.txt` до применения пресета. Ревизия входной

## Обновление

После изменения Minecraft, Fabric или списка модов актуализируйте снимок
реестра и повторно проверьте контексты. Если раскладка игрока расходится
со штатным реестром, сохраните снимок реестра и внесите отличия в генератор.
Порядок проверки и подготовки файла:

```text
python -B tools/keybinds/build_preset.py
python -B tools/keybinds/check_preset.py
```

Проверяющий скрипт принимает `--options` для сверки пресета с сохранённой
раскладкой. Упаковщик сверяет файл с генератором и включает его в архив
`launcher`. Обновите lock и опубликуйте обычный `pack-latest` по README.
